# WEB I — Missões

Material da disciplina **II1LDW · Linguagem e Desenvolvimento Web I**
Técnico em Informática para Internet integrado ao Ensino Médio
IFCE — Campus Horizonte · Prof. Stelio Bastos

35 missões práticas de HTML, CSS e JavaScript, uma por sexta-feira ao longo de 2026.
Cada missão tem editor de código com prévia ao vivo, correção instantânea e envio das
respostas ao final.

## Como usar

Abra a página inicial e escolha a missão do dia. Não é preciso instalar nada —
só um navegador.

## Aviso

Este repositório contém **apenas o material do aluno**. Gabaritos, guia de
regência e a automação de correção não fazem parte dele.
